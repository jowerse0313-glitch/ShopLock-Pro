# ShopLock-Pro Changelog

## 1.2.0
- Added configurable deployment settings via `shoplock.config.json`
- Added customer/site metadata to scan reports and customer summaries
- Added explicit support for known-good device management
- Improved the interactive menu with deployment settings and customer summary export
- Added stronger enterprise-style logging for supportability
- Hardened report quality with confidence and classification tracking

## 1.1.0
- Improved scan reliability with live neighbor table + ARP fallback logic
- Added narrow subnet validation for incomplete ARP results
- Improved monitor stability and cleanup behavior
- Added more filtering for junk/invalid MAC addresses

## 1.0.0
- Initial release of the Windows-based ShopLock toolkit
- Network scan report generation
- Background monitoring task support
- Quick lockdown checklist and customer-facing sales material
